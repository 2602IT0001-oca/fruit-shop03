# 07-08 Devise ユーザ認証

ここが現在の主な問題箇所。

## 現在存在するUser関連

- app/controllers/users_controller.rb
- app/helpers/users_helper.rb
- app/models/user.rb
- app/views/users/
- db/migrate/20260925045616_create_users.rb
- db/migrate/20260925052508_add_devise_to_users.rb
- config/initializers/devise.rb
- config/locales/devise.en.yml

## 問題点

DeviseでUserを生成する前に、
scaffoldまたは通常のUserモデルが作成されている。

教材ではDeviseを使う場合、

rails g devise User

を使う想定。

既存の create_users migration ですでに

email

カラムを作成している。

その後の add_devise_to_users migration でも

email

を追加しようとしているため、
migrationの競合に注意する必要がある。

現在のUserテーブルには

- name
- age
- password
- email

などが存在している。

Deviseでは通常passwordそのものをDBへ保存せず、

encrypted_password

を使用する。

## Devise側で必要になる主な項目

- email
- encrypted_password
- reset_password_token
- remember_created_at

教材ではさらに

- admin_flg
- sign_in_count
- current_sign_in_at
- last_sign_in_at

などを使用する。

## Userモデル

現在はDeviseに

- database_authenticatable
- registerable
- recoverable
- rememberable
- validatable

などが設定されている。

教材では途中でtrackableを使用する。
